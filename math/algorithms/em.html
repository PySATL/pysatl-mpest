EM#

Назначение: описать итерацию EM для конечной смеси, доказать, что она не уменьшает правдоподобие, и показать, как оценщик EM реализует итерацию и где код отступает от условий теорем.

Идея#

Максимизировать правдоподобие наблюдаемых данных (2) напрямую трудно: логарифм стоит перед суммой по компонентам. EM [1] вместо этого на каждой итерации максимизирует Q-функцию (5). В ней нет логарифма суммы, и она распадается на независимые задачи. Рост \(Q\) гарантирует рост правдоподобия.

Итерация#

Итерация \(t \to t + 1\) состоит из двух шагов:

  1. E-шаг. По текущим параметрам \(\Psi^{(t)}\) вычисляются ответственности (4), а значит, и функция \(Q(\cdot \mid \Psi^{(t)})\).

  2. M-шаг. Новые параметры — точка максимума \(Q\):

(6)#\[ \Psi^{(t+1)} = \arg\max_{\Psi} Q(\Psi \mid \Psi^{(t)}). \]

Сгруппируем слагаемые (5) по тому, от каких параметров они зависят:

(7)#\[ Q(\Psi \mid \Psi^{(t)}) = \underbrace{\sum_{j=1}^{k} \Bigl(\sum_{i=1}^{n} \gamma_{ij}^{(t)}\Bigr) \ln \omega_j}_{\text{только веса}} + \sum_{j=1}^{k} \underbrace{\sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j)}_{\text{только } \theta_j}. \]

Первое слагаемое зависит только от весов, каждое слагаемое второй суммы — только от параметров своей компоненты. Поэтому M-шаг (6) распадается на \(k + 1\) независимых задач: одну для весов и по одной для каждой компоненты.

Веса#

Обозначим ожидаемое число наблюдений \(j\)-й компоненты:

(8)#\[ n_j^{(t)} = \sum_{i=1}^{n} \gamma_{ij}^{(t)}. \]

Слагаемое весов в (7) максимизируется при ограничении на сумму весов:

\[ \max_{\omega} \sum_{j=1}^{k} n_j^{(t)} \ln \omega_j \quad \text{при} \quad \sum_{j=1}^{k} \omega_j = 1. \]

Функция Лагранжа и условие её стационарности:

\[ \Lambda(\omega, \lambda) = \sum_{j=1}^{k} n_j^{(t)} \ln \omega_j - \lambda \Bigl(\sum_{j=1}^{k} \omega_j - 1\Bigr), \qquad \frac{\partial \Lambda}{\partial \omega_j} = \frac{n_j^{(t)}}{\omega_j} - \lambda = 0 \;\Longrightarrow\; \omega_j = \frac{n_j^{(t)}}{\lambda}. \]

Сумма ответственностей в каждой строке равна единице, поэтому

\[ \lambda = \lambda \sum_{j=1}^{k} \omega_j = \sum_{j=1}^{k} n_j^{(t)} = \sum_{i=1}^{n} \sum_{j=1}^{k} \gamma_{ij}^{(t)} = n, \]

и новые веса равны

(9)#\[ \omega_j^{(t+1)} = \frac{n_j^{(t)}}{n} = \frac{1}{n} \sum_{i=1}^{n} \gamma_{ij}^{(t)}. \]

Параметры компонент#

Для \(j\)-й компоненты остаётся задача

(10)#\[ \theta_j^{(t+1)} = \arg\max_{\theta_j} \sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j). \]

Это оценка максимального правдоподобия для одного распределения, в которой наблюдение \(x_i\) входит с весом \(\gamma_{ij}^{(t)}\). Для некоторых семейств и параметризаций у (10) есть решение в явном виде, для остальных её решает численный оптимизатор. Какие пары семейства и параметризации решаются в явном виде и как, описано на странице стратегии q_function.

Свойства#

Для монотонности не нужен точный максимум (6): достаточно, чтобы M-шаг не уменьшал \(Q\).

Definition 3 (Обобщённый EM)

Итерация называется итерацией обобщённого EM (GEM), если

\[ Q(\Psi^{(t+1)} \mid \Psi^{(t)}) \ge Q(\Psi^{(t)} \mid \Psi^{(t)}). \]

Итерация EM (6) — частный случай GEM. К GEM относятся и CM-шаги ECM: каждый из них максимизирует \(Q\) по части параметров и потому её не уменьшает.

Theorem 1 (Монотонность GEM)

Если итерация \(\Psi^{(t)} \to \Psi^{(t+1)}\) — итерация обобщённого EM, то

\[ \ln L(\Psi^{(t+1)} \mid x) \ge \ln L(\Psi^{(t)} \mid x). \]

Proof. По определению ответственностей (4) для любых параметров \(\Psi\)

\[ \ln f(x_i \mid \Psi) = \ln \omega_j + \ln f_j(x_i \mid \theta_j) - \ln \gamma_{ij}(\Psi) \qquad \text{при } \gamma_{ij}(\Psi) > 0. \]

Левая часть от \(j\) не зависит. Умножим равенство на \(\gamma_{ij}^{(t)}\) и сложим по \(j\) и по \(i\). Так как

\[ \sum_{j=1}^{k} \gamma_{ij}^{(t)} = 1, \]

получаем

(11)#\[ \ln L(\Psi \mid x) = Q(\Psi \mid \Psi^{(t)}) - R(\Psi \mid \Psi^{(t)}), \qquad R(\Psi \mid \Psi^{(t)}) = \sum_{i=1}^{n} \sum_{j=1}^{k} \gamma_{ij}^{(t)} \ln \gamma_{ij}(\Psi). \]

Строки \(\gamma_i^{(t)}\) и \(\gamma_i(\Psi)\) — распределения вероятностей на \(\{1, \dots, k\}\). По неравенству Гиббса для любых распределений \(p\) и \(q\)

\[ \sum_{j=1}^{k} p_j \ln q_j \le \sum_{j=1}^{k} p_j \ln p_j, \]

поэтому при любом \(\Psi\)

\[ R(\Psi \mid \Psi^{(t)}) \le R(\Psi^{(t)} \mid \Psi^{(t)}). \]

Вычитая (11) при \(\Psi = \Psi^{(t)}\) из (11) при \(\Psi = \Psi^{(t+1)}\), получаем

\[ \ln L(\Psi^{(t+1)} \mid x) - \ln L(\Psi^{(t)} \mid x) = \underbrace{\bigl[Q(\Psi^{(t+1)} \mid \Psi^{(t)}) - Q(\Psi^{(t)} \mid \Psi^{(t)})\bigr]}_{\ge 0 \text{ по условию}} - \underbrace{\bigl[R(\Psi^{(t+1)} \mid \Psi^{(t)}) - R(\Psi^{(t)} \mid \Psi^{(t)})\bigr]}_{\le 0} \ge 0. \]

Теорема Theorem 1 доказана в Dempster et al.[1]; здесь доказательство записано для смеси, где \(R\) выражается через ответственности явно. Монотонность ещё не означает сходимости к точке максимума. Условия сходимости дал Wu[2].

Theorem 2 (Сходимость EM)

Обозначим множество параметров, при которых правдоподобие не меньше начального:

\[ \Omega_0 = \bigl\{\Psi : L(\Psi \mid x) \ge L(\Psi^{(0)} \mid x)\bigr\}. \]

Пусть выполнены условия:

  1. \(\Omega_0\) компактно;

  2. \(L\) непрерывна на \(\Omega_0\) и дифференцируема внутри пространства параметров;

  3. \(Q(\Psi \mid \Phi)\) непрерывна по обоим аргументам.

Тогда каждая предельная точка \(\Psi^*\) последовательности EM — стационарная точка правдоподобия, и для некоторой такой точки

\[ \nabla L(\Psi^* \mid x) = 0, \qquad L(\Psi^{(t)} \mid x) \nearrow L(\Psi^* \mid x) \quad \text{при} \quad t \to \infty. \]

Формулировка приведена по Wu[2] и McLachlan and Krishnan[3]; доказательство опирается на теорему Зангвилла о глобальной сходимости и здесь не повторяется. Из теоремы следуют два практических вывода.

Зависимость от начальной точки. Стационарная точка может быть локальным максимумом или седловой точкой, поэтому результат EM зависит от начальной смеси, которую передают в fit.

Вырождение. Условие компактности для смесей обычно не выполняется. Например, правдоподобие смеси нормальных распределений неограниченно [4]:

\[ \mu_j = x_i, \quad \sigma_j \to 0 \quad \Longrightarrow \quad \ln L(\Psi \mid x) \to +\infty. \]

Последовательность EM может уйти к такому вырожденному решению.

Оценщик EM строит по одному блоку на компоненту. Блок без имён параметров обновляет все свободные параметры компоненты; параметры, зафиксированные через family.view(...), не меняются. Блоки разных компонент решают независимые задачи из разложения (7), поэтому MaximizationStep вычисляет их в одной волне из одного снимка смеси.

WeightsStep вычисляет (9) и передаёт логарифмы весов в MixtureModel.with_log_weights, который их нормирует. Нормировка совпадает с (9), когда все строки state.H дают в сумме единицу. Если у наблюдения строка нулевая, потому что оно вне носителя всех компонент, то фактически

\[ \omega_j^{(t+1)} = \frac{n_j^{(t)}}{n'}, \qquad n' = \#\bigl\{i : \textstyle\sum_{j} \gamma_{ij}^{(t)} = 1\bigr\}, \]

то есть такие наблюдения просто исключаются из оценки весов.

Отступления от теории#

Теорема Theorem 1 верна для итерации, которая точно следует определению Definition 3. В коде есть места, где это условие выполняется только при оговорках или не выполняется совсем.

Численный M-шаг. Если для пары «семейство, параметризация» нет решения в явном виде, задачу (10) решает оптимизатор из optimizer, начиная с \(\theta_j^{(t)}\). Он находит не точный максимум, и итерация остаётся итерацией GEM, только если найденная точка не хуже стартовой:

\[ \sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j^{(t+1)}) \ge \sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j^{(t)}). \]

Контракт Optimizer требует вернуть лучшую найденную точку. Для ScipyNelderMead условие выполняется: стартовая точка входит в начальный симплекс, а метод возвращает лучшую его вершину. Для ScipyPowell выполнение условия не проверено.

Защита от вырождения. В вырожденных случаях решения в явном виде оставляют параметры прежними; условия перечислены в таблице Защита от вырождения. Оставить параметры прежними — значит не уменьшить \(Q\), поэтому итерация остаётся итерацией GEM. Цель защиты — не дать последовательности уйти к вырожденному решению с \(\sigma_j \to 0\).

Жёсткий E-шаг. При ExpectationStep(is_soft=False) строки state.H — индикаторы, а не апостериорные вероятности, и тождество (11) не выполняется. Такой вариант известен как классификационный EM [5]; теорема Theorem 1 для него рост правдоподобия не гарантирует.

Удаление компонент. Правила pruners срабатывают после M-шага. Удалённая компонента исчезает из смеси, веса остальных перенормируются, и правдоподобие может уменьшиться. Монотонность гарантирована только для итераций, в которых ни одна компонента не удалена.
