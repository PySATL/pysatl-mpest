pysatl_mpest.estimators.iterative#

Iterative estimation pipeline, steps, stopping criteria, and pruners.

Pipeline#

Pipeline

Iterative mixture model parameter estimator.

PipelineState

State container passed between pipeline steps and pruners.

Base Classes#

PipelineStep

Abstract base class for a single processing step in an iterative pipeline.

Breakpointer

Abstract base class for pipeline stopping conditions.

Pruner

Abstract base class for component pruning strategies.

Implementations#

Concrete steps, stopping criteria and pruners for building a pipeline.

Steps (PipelineStep):#

ExpectationStep

Expectation step computing component responsibility matrix H.

WeightsStep

Mixture weights update step for iterative estimation pipelines.

MaximizationStep

Maximization step updating mixture component parameters.

M-step configuration (MaximizationStep):#

OptimizationBlock

Configuration task for optimizing a mixture component in MaximizationStep.

MaximizationStrategy

Available parameter update strategies for MaximizationStep.

Breakpointers (Breakpointer):#

StepBreakpointer

Stops the pipeline after a fixed number of iterations.

LikelihoodBreakpointer

Stops the pipeline when the log-likelihood of the mixture converges.

Pruners (Pruner):#

PriorThresholdPruner

Component pruner based on a prior weight threshold.
