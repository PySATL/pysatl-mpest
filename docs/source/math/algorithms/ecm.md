# ECM
**Назначение:** описать, как ECM заменяет M-шаг последовательностью условных максимизаций, показать, что итерация остаётся монотонной, и объяснить, как оценщик `ECM` строит CM-шаги из `parameter_groups`.

## Идея

В EM M-шаг {eq}`eq-em-component` максимизирует $Q$ сразу по всем параметрам компоненты. Если параметров много или совместный максимум не выражается в явном виде, эта задача трудна. ECM {footcite:p}`meng1993ecm` заменяет её последовательностью {term}`CM-шагов <CM-шаг>`: каждый максимизирует $Q$ только по группе параметров, а остальные фиксирует на последних известных значениях. Каждая такая задача проще: в ней меньше параметров, и у неё чаще есть решение в явном виде.

## Итерация

Разобьём параметры $j$-й компоненты на упорядоченные непересекающиеся группы:

$$
\theta_j = \bigl(\theta_j^{[1]}, \dots, \theta_j^{[S_j]}\bigr).
$$

Итерация $t \to t + 1$ состоит из таких шагов:

1. **E-шаг.** Как в EM: по $\Psi^{(t)}$ вычисляются ответственности {eq}`eq-responsibilities`.
2. **CM-шаг для весов.** Веса обновляются по {eq}`eq-em-weights`. Это точный максимум $Q$ по весам: слагаемое весов в {eq}`eq-q-split` не зависит от параметров компонент.
3. **CM-шаги для компонент.** Для каждой компоненты $j$ по порядку групп $s = 1, \dots, S_j$:

$$
\theta_j^{[s]} \leftarrow \arg\max_{\theta_j^{[s]}} \sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j\bigl(x_i \mid \theta_j^{[1]}, \dots, \theta_j^{[s]}, \dots, \theta_j^{[S_j]}\bigr).
$$ (eq-ecm-cm-step)

В {eq}`eq-ecm-cm-step` группы с номерами меньше $s$ уже обновлены на этой итерации, а группы с номерами больше $s$ ещё имеют значения с итерации $t$.

Все CM-шаги одной итерации максимизируют одну и ту же функцию $Q(\cdot \mid \Psi^{(t)})$: ответственности между CM-шагами не пересчитываются. По разложению {eq}`eq-q-split` CM-шаги разных компонент решают независимые задачи, поэтому порядок важен только между группами одной компоненты. При $S_j = 1$ CM-шаг совпадает с M-шагом EM {eq}`eq-em-component`.

## Свойства

````{prf:theorem} Монотонность ECM
:label: thm-ecm-monotone

Итерация ECM — итерация {term}`обобщённого EM <Обобщённый EM>`, поэтому она не уменьшает правдоподобие наблюдаемых данных.
````

````{prf:proof}
Пусть итерация состоит из $C$ CM-шагов, и $\Psi^{(t, c)}$ — параметры после $c$-го из них:

$$
\Psi^{(t, 0)} = \Psi^{(t)}, \qquad \Psi^{(t, C)} = \Psi^{(t+1)}.
$$

Каждый CM-шаг максимизирует $Q(\cdot \mid \Psi^{(t)})$ по части параметров, а текущее значение этой части — одна из допустимых точек, поэтому

$$
Q(\Psi^{(t, c)} \mid \Psi^{(t)}) \ge Q(\Psi^{(t, c-1)} \mid \Psi^{(t)}), \qquad c = 1, \dots, C.
$$

Складывая неравенства по $c$, получаем

$$
Q(\Psi^{(t+1)} \mid \Psi^{(t)}) \ge Q(\Psi^{(t)} \mid \Psi^{(t)}),
$$

то есть определение {prf:ref}`def-gem`. Монотонность правдоподобия следует из теоремы {prf:ref}`thm-gem-monotone`.
````

Доказательство использует только то, что каждый CM-шаг не уменьшает $Q$. Поэтому оно верно и для CM-шагов, которые находят не точный максимум, а лишь не ухудшают текущую точку. {footcite:t}`meng1993ecm` показывают, что ECM сохраняет свойства сходимости EM, в том числе монотонный рост правдоподобия.

### Пример: нормальная компонента

Для нормальной компоненты с параметрами $\mu_j$ и $\sigma_j$ целевая функция CM-шага {eq}`eq-ecm-cm-step` с точностью до константы равна

$$
\sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \mu_j, \sigma_j) = -n_j^{(t)} \ln \sigma_j - \frac{1}{2 \sigma_j^2} \sum_{i=1}^{n} \gamma_{ij}^{(t)} (x_i - \mu_j)^2 + \text{const}.
$$

Обозначим взвешенное среднее:

$$
\bar{x}_j = \frac{1}{n_j^{(t)}} \sum_{i=1}^{n} \gamma_{ij}^{(t)} x_i.
$$

Приравнивая нулю частные производные, получаем условные максимумы (вывод — в разделе {ref}`math-q-normal`):

$$
\mu_j = \bar{x}_j \quad \text{при любом } \sigma_j, \qquad \sigma_j^2 = \frac{1}{n_j^{(t)}} \sum_{i=1}^{n} \gamma_{ij}^{(t)} (x_i - \mu_j)^2 \quad \text{при фиксированном } \mu_j.
$$ (eq-ecm-normal)

Порядок групп влияет на результат.

**Группы `[{"mu"}, {"sigma"}]`.** Сначала $\mu_j = \bar{x}_j$, затем $\sigma_j^2$ по {eq}`eq-ecm-normal` относительно нового $\mu_j$. Условный максимум по $\mu_j$ не зависит от $\sigma_j$, поэтому результат совпадает с итерацией EM.

**Группы `[{"sigma"}, {"mu"}]`.** Сначала $\sigma_j^2$ вычисляется относительно старого $\mu_j^{(t)}$, затем $\mu_j = \bar{x}_j$. Из разложения суммы квадратов

$$
\sum_{i=1}^{n} \gamma_{ij}^{(t)} \bigl(x_i - \mu_j^{(t)}\bigr)^2 = \sum_{i=1}^{n} \gamma_{ij}^{(t)} (x_i - \bar{x}_j)^2 + n_j^{(t)} \bigl(\bar{x}_j - \mu_j^{(t)}\bigr)^2
$$

следует, что новая дисперсия больше, чем у EM:

$$
\sigma_{j, \text{ECM}}^2 = \sigma_{j, \text{EM}}^2 + \bigl(\bar{x}_j - \mu_j^{(t)}\bigr)^2.
$$

Итерация отличается от EM, но по теореме {prf:ref}`thm-ecm-monotone` остаётся монотонной.

Стратегия `QFUNCTION` для пары (`Normal`, `meanStd`) реализует ровно формулы {eq}`eq-ecm-normal`: если в блоке есть только `sigma`, дисперсия считается относительно текущего `mu` компоненты.

## Реализация в библиотеке

| Понятие | В коде |
|---|---|
| разбиение $\theta_j$ на группы | `parameter_groups[j]` — список множеств имён параметров в аргументе `ECM.fit` |
| CM-шаг {eq}`eq-ecm-cm-step` для группы $s$ | блок `OptimizationBlock(j, group, MaximizationStrategy.QFUNCTION)` |
| CM-шаг для весов | `WeightsStep`, до всех CM-шагов компонент |
| одна $Q(\cdot \mid \Psi^{(t)})$ на итерацию | одна `state.H` на все блоки `MaximizationStep` |
| порядок CM-шагов | порядок блоков: по компонентам, внутри компоненты — по порядку групп |

`ECM.fit` строит блоки функцией `build_optimization_blocks`. Группы компоненты должны быть непустыми, не пересекаться и вместе покрывать все её свободные параметры; иначе `fit` бросает `ValueError`. Компонента, которой нет в `parameter_groups`, получает один блок на все параметры, и для неё итерация совпадает с EM. Без `parameter_groups` `ECM` делает то же, что `EM`.

`MaximizationStep` выполняет блоки волнами. Блоки одной компоненты попадают в разные волны в порядке списка, поэтому каждый следующий CM-шаг видит параметры, обновлённые предыдущими, как в {eq}`eq-ecm-cm-step`. Блоки разных компонент со стратегией `QFUNCTION` независимы по {eq}`eq-q-split` и могут выполняться в одной волне.

## Отступления от теории

Для ECM верны те же оговорки, что и для [EM](em.md): численный CM-шаг сохраняет монотонность, только если оптимизатор не возвращает точку хуже стартовой, а {term}`жёсткий E-шаг <Жёсткий E-шаг>` и {term}`удаление компонент <Удаление компонент>` выводят итерацию за рамки теоремы. Подробно — в разделе {ref}`math-em-deviations`.
