# Предметная область и сценарии
**Назначение:** показать доступные методы оценки смеси, рабочий сценарий исследователя и точки расширения библиотеки.

## Дерево алгоритмов

[Исходник дерева алгоритмов](diagrams/algorithms-tree.drawio "Algorithms tree")

В библиотеке доступны три оценщика семейства EM. Они вычисляют ответственности на E-шаге и различаются способом обновления параметров.

- `EM` максимизирует Q-функцию по всем свободным параметрам каждой компоненты совместно.
- `ECM` позволяет разбить параметры на группы и максимизирует Q-функцию по ним по очереди, фиксируя остальные параметры.
- `ECME` выбирает для каждой компоненты, максимизировать Q-функцию или правдоподобие наблюдаемых данных напрямую. По умолчанию (`default_strategy="odl"`) все компоненты максимизируют правдоподобие.

Математика и точные различия M-шагов — в разделе [«EM-подобные алгоритмы»](../math/algorithms/index.md), выбор оценщика на практике — в [руководстве](../user_guide/estimators.md).

Методы Монте-Карло и прямые методы оценки запланированы.

## Сценарий работы

[Исходник схемы сценария](diagrams/activity.drawio "Activity")

Сегодня исследователь задаёт число компонент, их семейства и начальные параметры, собирает `MixtureModel` и передаёт её вместе с выборкой в `fit`. Ветви подбора структуры и автоматической инициализации на схеме запланированы. Порядок вычислений после вызова `fit` описан на странице [«Поведение»](behavior.md).
