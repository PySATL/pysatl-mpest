# Модуль `structure_selection`
**Назначение:** обозначить место для выбора структуры смеси — числа компонент и их семейств — по выборке (Запланировано).

Модуля в коде пока нет. Сейчас число компонент и их семейства задаёт пользователь при создании `MixtureModel`, см. [«Модуль `core`»](../core/core.md).
