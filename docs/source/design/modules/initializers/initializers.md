# Модуль `initializers`
**Назначение:** обозначить место для подбора начальных параметров смеси по выборке и заданным семействам компонент (Запланировано).

Модуля в коде пока нет. Сейчас начальную `MixtureModel` с параметрами задаёт пользователь, см. [«Модуль `core`»](../core/core.md).
