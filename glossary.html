Глоссарий#

Назначение: дать короткие определения терминов, которыми пользуется документация, и указать, где каждый термин разобран подробно.

Английское название в скобках — то, которым термин назван в коде и в литературе.

CM-шаг#

(conditional maximization step) Шаг ECM, который максимизирует Q-функцию по группе параметров при фиксированных остальных. В коде — блок OptimizationBlock с непустым набором имён параметров. См. EM-подобные алгоритмы.

E-шаг#

(expectation step) Шаг итерации, на котором по текущим параметрам вычисляются ответственности и тем самым Q-функция. В коде — ExpectationStep.

M-шаг#

(maximization step) Шаг итерации, на котором параметры смеси обновляются так, чтобы увеличить Q-функцию или правдоподобие наблюдаемых данных. В коде — WeightsStep для весов и MaximizationStep для параметров компонент.

Q-функция#

(Q-function) Математическое ожидание логарифма правдоподобия полных данных по распределению меток при текущих параметрах. См. Q-функция.

Апостериорная вероятность принадлежности#
Ответственность#

(responsibility) Вероятность \(\gamma_{ij}\) того, что наблюдение \(x_i\) порождено \(j\)-й компонентой, при текущих параметрах смеси. Вычисляется на E-шаге; матрица ответственностей хранится в state.H. См. Апостериорные вероятности.

Блок оптимизации#

(optimization block) Единица работы MaximizationStep: компонента, набор её параметров и стратегия. В коде — OptimizationBlock. См. Стратегии M-шага.

Вес компоненты#

(weight) Вероятность \(\omega_j\) того, что наблюдение порождено \(j\)-й компонентой. Веса неотрицательны и в сумме дают единицу; MixtureModel хранит их логарифмы.

Волна#

(wave) Группа блоков оптимизации, которые MaximizationStep вычисляет из одного снимка смеси. Разбиение строит plan_waves. См. Волны M-шага.

Жёсткий E-шаг#

(hard E-step) Вариант E-шага, при котором каждое наблюдение целиком относится к компоненте с наибольшей ответственностью. Включается параметром ExpectationStep(is_soft=False).

Компонента#

(component) Одно из распределений \(f_j(\cdot \mid \theta_j)\), из которых складывается конечная смесь. В библиотеке — распределение ParametricFamilyDistribution из pysatl-core.

Конечная смесь#

(finite mixture) Распределение с плотностью \(\sum_j \omega_j f_j(x \mid \theta_j)\). В коде — MixtureModel. См. Плотность смеси.

Критерий остановки#

(breakpointer) Правило, по которому конвейер решает, выполнять ли следующую итерацию, например по изменению правдоподобия или по числу итераций. В коде — подклассы Breakpointer.

Обобщённый EM#

(generalized EM, GEM) Итерация, которая не обязательно максимизирует Q-функцию, но не уменьшает её. Для неё уже верна монотонность правдоподобия. См. Определение 3.

Параметризация#

(parametrization) Способ задать параметры распределения одного семейства, например meanStd для нормального распределения. Аналитические стратегии M-шага выбираются по паре «семейство, параметризация».

Полные данные#

(complete data) Выборка вместе с ненаблюдаемыми метками компонент, породивших каждое наблюдение. См. Скрытые переменные и полные данные.

Правдоподобие наблюдаемых данных#

(observed-data likelihood, ODL) Правдоподобие смеси по самой выборке, без меток компонент. Его логарифм считает MixtureModel.loglikelihood. См. Правдоподобие наблюдаемых данных.

Семейство#

(family) Параметрическое семейство распределений pysatl-core, например Normal или Exponential; в коде задаётся FamilyName.

Стратегия M-шага#

(maximization strategy) Способ вычислить новые параметры блока: максимизация Q-функции, правдоподобия наблюдаемых данных или сопоставление моментов. В коде — перечисление MaximizationStrategy. См. Стратегии M-шага.

Удаление компонент#

(pruning) Удаление из смеси компонент по правилу, например с весом ниже порога, после M-шага. Веса оставшихся компонент перенормируются. В коде — подклассы Pruner.
