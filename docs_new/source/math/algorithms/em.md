# EM
**Назначение:** описать итерацию EM для конечной смеси, доказать, что она не уменьшает правдоподобие, и показать, как оценщик `EM` реализует итерацию и где код отступает от условий теорем.

## Идея

Максимизировать правдоподобие наблюдаемых данных {eq}`eq-observed-loglik` напрямую трудно: логарифм стоит перед суммой по компонентам. EM {footcite:p}`dempster1977em` вместо этого на каждой итерации максимизирует {term}`Q-функцию <Q-функция>` {eq}`eq-q-function`, в которой логарифма суммы нет и которая распадается на независимые задачи. Рост $Q$ гарантирует рост правдоподобия.

(math-em-iteration)=
## Итерация

Итерация $t \to t + 1$ состоит из двух шагов:

1. **E-шаг.** По текущим параметрам $\Psi^{(t)}$ вычисляются ответственности $\gamma_{ij}^{(t)}$ {eq}`eq-responsibilities`, а значит, и функция $Q(\cdot \mid \Psi^{(t)})$.
2. **M-шаг.** Новые параметры — точка максимума $Q$:

$$
\Psi^{(t+1)} = \arg\max_{\Psi} Q(\Psi \mid \Psi^{(t)}).
$$ (eq-em-m-step)

Сгруппируем слагаемые {eq}`eq-q-function` по тому, от каких параметров они зависят:

$$
Q(\Psi \mid \Psi^{(t)}) = \underbrace{\sum_{j=1}^{k} \Bigl(\sum_{i=1}^{n} \gamma_{ij}^{(t)}\Bigr) \ln \omega_j}_{\text{только веса}} + \sum_{j=1}^{k} \underbrace{\sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j)}_{\text{только } \theta_j}.
$$ (eq-q-split)

Первое слагаемое зависит только от весов, каждое слагаемое второй суммы — только от параметров своей компоненты. Поэтому M-шаг {eq}`eq-em-m-step` распадается на $k + 1$ независимых задач: одну для весов и по одной для каждой компоненты.

### Веса

Обозначим $n_j^{(t)} = \sum_{i=1}^{n} \gamma_{ij}^{(t)}$ — ожидаемое число наблюдений $j$-й компоненты. Нужно максимизировать $\sum_j n_j^{(t)} \ln \omega_j$ при условии $\sum_j \omega_j = 1$. Функция Лагранжа $\sum_j n_j^{(t)} \ln \omega_j - \lambda \bigl(\sum_j \omega_j - 1\bigr)$ даёт условия $n_j^{(t)} / \omega_j = \lambda$, то есть $\omega_j \propto n_j^{(t)}$. Сумма ответственностей в каждой строке равна единице, поэтому $\sum_j n_j^{(t)} = n$ и

$$
\omega_j^{(t+1)} = \frac{n_j^{(t)}}{n} = \frac{1}{n} \sum_{i=1}^{n} \gamma_{ij}^{(t)}.
$$ (eq-em-weights)

### Параметры компонент

Для $j$-й компоненты остаётся задача

$$
\theta_j^{(t+1)} = \arg\max_{\theta_j} \sum_{i=1}^{n} \gamma_{ij}^{(t)} \ln f_j(x_i \mid \theta_j),
$$ (eq-em-component)

то есть оценка максимального правдоподобия для одного распределения, в которой наблюдение $x_i$ входит с весом $\gamma_{ij}^{(t)}$. Для некоторых семейств и параметризаций у {eq}`eq-em-component` есть решение в явном виде, для остальных её решает численный оптимизатор. Какие пары семейства и параметризации решаются аналитически, описано на странице стратегии `q_function`.

## Свойства

Для монотонности не нужен точный максимум {eq}`eq-em-m-step`: достаточно, чтобы M-шаг не уменьшал $Q$.

````{prf:definition} Обобщённый EM
:label: def-gem

Итерация называется итерацией обобщённого EM (GEM), если новые параметры не уменьшают Q-функцию:

$$
Q(\Psi^{(t+1)} \mid \Psi^{(t)}) \ge Q(\Psi^{(t)} \mid \Psi^{(t)}).
$$
````

Итерация EM {eq}`eq-em-m-step` — частный случай GEM. К GEM относятся и {term}`CM-шаги <CM-шаг>` `ECM`: каждый из них максимизирует $Q$ по части параметров и потому её не уменьшает.

````{prf:theorem} Монотонность GEM
:label: thm-gem-monotone

Если итерация $\Psi^{(t)} \to \Psi^{(t+1)}$ — итерация обобщённого EM, то правдоподобие наблюдаемых данных не уменьшается:

$$
\ln L(\Psi^{(t+1)} \mid x) \ge \ln L(\Psi^{(t)} \mid x).
$$
````

````{prf:proof}
По определению ответственностей {eq}`eq-responsibilities` для любых параметров $\Psi$ и любой пары $i, j$ с $\gamma_{ij}(\Psi) > 0$

$$
\ln f(x_i \mid \Psi) = \ln \omega_j + \ln f_j(x_i \mid \theta_j) - \ln \gamma_{ij}(\Psi).
$$

Левая часть от $j$ не зависит. Умножим равенство на $\gamma_{ij}^{(t)}$, сложим по $j$ (сумма $\gamma_{ij}^{(t)}$ по $j$ равна единице) и по $i$:

$$
\ln L(\Psi \mid x) = Q(\Psi \mid \Psi^{(t)}) - R(\Psi \mid \Psi^{(t)}), \qquad R(\Psi \mid \Psi^{(t)}) = \sum_{i=1}^{n} \sum_{j=1}^{k} \gamma_{ij}^{(t)} \ln \gamma_{ij}(\Psi).
$$

Строки $\gamma_i^{(t)}$ и $\gamma_i(\Psi)$ — распределения вероятностей на $\{1, \dots, k\}$. По неравенству Гиббса $\sum_j p_j \ln q_j \le \sum_j p_j \ln p_j$ для любых распределений $p$ и $q$, поэтому $R(\Psi \mid \Psi^{(t)}) \le R(\Psi^{(t)} \mid \Psi^{(t)})$ при любом $\Psi$. Отсюда

$$
\ln L(\Psi^{(t+1)} \mid x) - \ln L(\Psi^{(t)} \mid x) = \underbrace{\bigl[Q(\Psi^{(t+1)} \mid \Psi^{(t)}) - Q(\Psi^{(t)} \mid \Psi^{(t)})\bigr]}_{\ge 0 \text{ по условию}} - \underbrace{\bigl[R(\Psi^{(t+1)} \mid \Psi^{(t)}) - R(\Psi^{(t)} \mid \Psi^{(t)})\bigr]}_{\le 0} \ge 0.
$$
````

Теорема {prf:ref}`thm-gem-monotone` доказана в {footcite:t}`dempster1977em`; здесь доказательство записано для смеси, где $R$ выражается через ответственности явно. Монотонность ещё не означает сходимости к точке максимума. Условия сходимости дал {footcite:t}`wu1983convergence`.

````{prf:theorem} Сходимость EM
:label: thm-em-convergence

Пусть множество $\{\Psi : L(\Psi \mid x) \ge L(\Psi^{(0)} \mid x)\}$ компактно, правдоподобие непрерывно на нём и дифференцируемо внутри пространства параметров, а $Q(\Psi \mid \Phi)$ непрерывна по обоим аргументам. Тогда все предельные точки последовательности EM — стационарные точки правдоподобия, а $L(\Psi^{(t)} \mid x)$ монотонно сходится к значению правдоподобия в одной из них.
````

Формулировка приведена по {footcite:t}`wu1983convergence` и {footcite:t}`mclachlan2008em`; доказательство опирается на теорему Зангвилла о глобальной сходимости и здесь не повторяется. Из теоремы следуют два практических вывода:

- Стационарная точка может быть локальным максимумом или седловой точкой. Результат EM зависит от начальной смеси, которую передают в `fit`.
- Условие компактности для смесей обычно не выполняется. Например, правдоподобие смеси нормальных распределений неограниченно: если $\mu_j = x_i$ и $\sigma_j \to 0$, то $\ln L \to +\infty$ {footcite:p}`mclachlan2000finite`. Последовательность EM может уйти к такому вырожденному решению.

## Реализация в библиотеке

| Понятие | В коде |
|---|---|
| итерация $t \to t + 1$ | один проход цикла `Pipeline.fit` |
| $\Psi^{(t)}$, $\Psi^{(t+1)}$ | `state.prev_mixture`, `state.curr_mixture` |
| E-шаг | `ExpectationStep` |
| M-шаг для весов {eq}`eq-em-weights` | `WeightsStep` |
| M-шаг для $\theta_j$ {eq}`eq-em-component` | блок `OptimizationBlock(j, None, MaximizationStrategy.QFUNCTION)` в `MaximizationStep` |
| остановка | `breakpointers`, например `LikelihoodBreakpointer` по изменению $\ln L$ |

Оценщик `EM` строит по одному блоку на компоненту. Блок без имён параметров обновляет все свободные параметры компоненты; параметры, зафиксированные через `family.view(...)`, не меняются. Блоки разных компонент решают независимые задачи из разложения {eq}`eq-q-split`, поэтому `MaximizationStep` вычисляет их в одной волне из одного снимка смеси.

`WeightsStep` вычисляет {eq}`eq-em-weights` и передаёт логарифмы весов в `MixtureModel.with_log_weights`, который их нормирует. Нормировка совпадает с {eq}`eq-em-weights`, когда все строки `state.H` дают в сумме единицу. Если у наблюдения строка нулевая, потому что оно вне носителя всех компонент, нормировка делит на число остальных наблюдений, то есть наблюдение просто исключается из оценки весов.

## Отступления от теории

Теорема {prf:ref}`thm-gem-monotone` верна для итерации, которая точно следует определению GEM. В коде есть места, где это условие выполняется только при оговорках или не выполняется совсем.

- **Численный M-шаг.** Если для пары «семейство, параметризация» нет аналитического решения, задачу {eq}`eq-em-component` решает оптимизатор из `optimizer`, начиная с текущих параметров. Он находит не точный максимум, и итерация остаётся итерацией GEM, только если оптимизатор не возвращает точку хуже стартовой. Контракт `Optimizer` требует вернуть лучшую найденную точку. Для `ScipyNelderMead` условие выполняется: стартовая точка входит в начальный симплекс, а метод возвращает лучшую его вершину. Для `ScipyPowell` выполнение условия не проверено.
- **Защита от вырождения.** Аналитические решения не обновляют параметры компоненты, если её $n_j^{(t)}$ почти равно нулю, и не обновляют $\sigma$ нормальной компоненты, если взвешенная дисперсия почти равна нулю. Оставить параметры прежними — значит не уменьшить $Q$, поэтому итерация остаётся итерацией GEM. Цель защиты — не дать последовательности уйти к вырожденному решению с $\sigma_j \to 0$.
- **{term}`Жёсткий E-шаг <Жёсткий E-шаг>`.** При `ExpectationStep(is_soft=False)` строки `state.H` — индикаторы, а не апостериорные вероятности, и тождество $\ln L = Q - R$ из доказательства теоремы {prf:ref}`thm-gem-monotone` не выполняется. Такой вариант известен как классификационный EM {footcite:p}`celeux1992cem`; теорема {prf:ref}`thm-gem-monotone` для него рост правдоподобия не гарантирует.
- **{term}`Удаление компонент <Удаление компонент>`.** Правила `pruners` срабатывают после M-шага. Удалённая компонента исчезает из смеси, веса остальных перенормируются, и правдоподобие может уменьшиться. Монотонность гарантирована только для итераций, в которых ни одна компонента не удалена.
