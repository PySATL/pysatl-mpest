# Стратегия `moments`
**Назначение:** описать эвристику `MOMENTS`, которая заменяет максимизацию $Q$ сопоставлением взвешенных моментов, показать, что для реализованных пар она совпадает с `q_function`, и перечислить, чего она не гарантирует.

## Идея

На M-шаге параметры компоненты $j$ подбираются так, чтобы её теоретические моменты совпали со взвешенными эмпирическими моментами, в которых наблюдение $x_i$ входит с весом $\gamma_{ij}^{(t)}$. Это эвристика: она не выводится из максимизации правдоподобия, и в общем случае теорема {prf:ref}`thm-gem-monotone` к ней не применима. Ни один оценщик библиотеки эту стратегию не использует; её можно задать блоку, собрав `Pipeline` вручную.

## Задача

Взвешенный начальный момент порядка $r$ для компоненты $j$:

$$
\hat{m}_{r,j}^{(t)} = \frac{1}{n_j} \sum_{i=1}^{n} \gamma_{ij}^{(t)} x_i^r, \qquad n_j = \sum_{i=1}^{n} \gamma_{ij}^{(t)}.
$$

Теоретический начальный момент компоненты: $m_{r}(\theta_j) = \int x^r f_j(x \mid \theta_j) \, dx$. Если у компоненты $M_j$ параметров, их находят из системы

$$
m_r(\theta_j) = \hat{m}_{r,j}^{(t)}, \qquad r = 1, \dots, M_j.
$$ (eq-moments-system)

Системы разных компонент независимы: система компоненты $j$ зависит только от выборки и столбца $\gamma_{\cdot j}^{(t)}$. Поэтому в `STRATEGY_ACCESS` стратегия `OWN_COMPONENT` (см. {ref}`math-strategy-access`). Веса обновляет `WeightsStep` по {eq}`eq-em-weights`, как и при других стратегиях.

## Реализации

Реализации в явном виде есть для двух пар; для остальных стратегия бросает `NotImplementedError`, запасного численного пути нет.

(math-moments-exponential)=
### `Exponential`, параметризация `rate`

Один параметр и одно уравнение: $m_1 = 1 / \lambda_j = \bar{x}_j$, откуда $\lambda_j = 1 / \bar{x}_j$. Это совпадает с решением `q_function` {eq}`eq-q-exponential`.

(math-moments-normal)=
### `Normal`, параметризация `meanStd`

Система {eq}`eq-moments-system` для двух параметров: $m_1 = \mu_j$, $m_2 = \mu_j^2 + \sigma_j^2$. Её решение — $\mu_j = \bar{x}_j$ и $\sigma_j^2 = \hat{m}_{2,j}^{(t)} - \bar{x}_j^2 = \frac{1}{n_j} \sum_i \gamma_{ij}^{(t)} (x_i - \bar{x}_j)^2$, то есть снова решение `q_function` {eq}`eq-q-normal`.

Если блок содержит только `sigma`, код считает $\sigma_j^2 = \frac{1}{n_j} \sum_i \gamma_{ij}^{(t)} (x_i - \mu_j)^2$ относительно текущего $\mu_j$ компоненты. Это условный максимум $Q_j$, как в `q_function`, а не решение уравнения для второго момента: из $m_2 = \mu_j^2 + \sigma_j^2$ при фиксированном $\mu_j$ получилось бы $\sigma_j^2 = \hat{m}_{2,j}^{(t)} - \mu_j^2$. Значения совпадают только при $\mu_j = \bar{x}_j$.

### Следствие

Для обеих реализованных пар стратегия `MOMENTS` вычисляет те же значения, что `QFUNCTION`, поэтому на них распространяется монотонность из теоремы {prf:ref}`thm-gem-monotone`. Для семейств, у которых оценки метода моментов и максимального правдоподобия различаются, это свойство пропадёт.

## Защита от вырождения

Как и в `q_function`, параметры не обновляются, если $n_j$ близко к нулю, $\sigma_j$ не обновляется при почти нулевой взвешенной дисперсии, а $\lambda_j$ — при $\bar{x}_j \le 10^{-9}$. Отличие одно: для $n_j$ стратегия проверяет $|n_j| \le 10^{-9}$ через `np.isclose`, а `q_function` — $n_j \le 10^{-9}$; для неотрицательных ответственностей это одно и то же.
