## Что делает библиотека

`pysatl-mpest` оценивает параметры конечных смесей распределений по выборке EM-подобными алгоритмами; компоненты смеси — параметрические распределения из `pysatl-core`.

## Контекст системы

Лист System context показывает место библиотеки в окружении, форматы входных и выходных данных, а также внешние зависимости.

[Исходник схемы контекста](diagrams/full-architecture.drawio "System context")

- Сейчас пользователь подаёт выборку `X` и начальную `MixtureModel`, которую сам собирает из компонент `pysatl-core` (`ParametricFamilyDistribution`), выбирает оценщик (`EM`, `ECM`, `ECME`) с критериями остановки (`breakpointers`), правилами удаления компонент (`pruners`) и оптимизатором, вызывает `fit` и получает обученную `MixtureModel`; историю итераций даёт свойство `history` (`IterationsHistory`).
- На листе на входе написан `EM(...)`; `ECM` и `ECME` принимают ту же базовую конфигурацию и дополнительно поддерживают разбиение параметров на группы.
- Два серых пути на листе запланированы: «`X` + семейства без параметров» (начальные параметры подбирает модуль `initializers`) и «только `X`» (модуль `structure_selection` подбирает число компонент и их семейства, затем начальные параметры) — Запланировано.
- Из зависимостей берутся: `pysatl-core` — параметрические семейства и распределения, конечная смесь (`FiniteMixtureDistribution`), стратегии сэмплирования; `scipy` — `optimize.minimize` (методы Nelder–Mead и Powell в `optimizers`) и `special.logsumexp`/`softmax`; `numpy` — массивы.

## Статус возможностей

| Возможность | Модуль | Статус |
| --- | --- | --- |
| Смесь распределений: плотность, логарифм правдоподобия, генерация выборки | `core` | Готово |
| Готовые оценщики `EM`, `ECM`, `ECME` | `estimators` | Готово |
| Собственный итеративный конвейер из шагов (`Pipeline`, `ExpectationStep`, `WeightsStep`, `MaximizationStep`) | `estimators.iterative` | Готово |
| Критерии остановки (`StepBreakpointer`, `LikelihoodBreakpointer`) | `estimators.iterative` | Готово |
| Удаление вырожденных компонент (`PriorThresholdPruner`) | `estimators.iterative` | Готово |
| Численные оптимизаторы (`ScipyNelderMead`, `ScipyPowell`) | `optimizers` | Готово |
| Прямые (неитеративные) методы оценки | `estimators.direct` | Запланировано |
| Подбор начального приближения | `initializers` | Запланировано |
| Выбор структуры смеси (число компонент и семейства) | `structure_selection` | Запланировано |
