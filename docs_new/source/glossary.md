# Глоссарий
**Назначение:** дать короткие определения терминов, которыми пользуется документация, и указать, где каждый термин разобран подробно.

Английское название в скобках — то, которым термин назван в коде и в литературе.

```{glossary}
:sorted:
Апостериорная вероятность принадлежности
Ответственность
  (responsibility) Вероятность $\gamma_{ij}$ того, что наблюдение $x_i$ порождено $j$-й компонентой, при текущих параметрах смеси. Вычисляется на {term}`E-шаге <E-шаг>`; матрица ответственностей хранится в `state.H`. См. {ref}`math-responsibilities`.

CM-шаг
  (conditional maximization step) Шаг `ECM`, который максимизирует {term}`Q-функцию <Q-функция>` по группе параметров при фиксированных остальных. В коде — блок `OptimizationBlock` с непустым набором имён параметров. См. [EM-подобные алгоритмы](math/algorithms/index.md).

Блок оптимизации
  (optimization block) Единица работы `MaximizationStep`: компонента, набор её параметров и {term}`стратегия <Стратегия M-шага>`. В коде — `OptimizationBlock`. См. [Стратегии M-шага](math/strategies/index.md).

Стратегия M-шага
  (maximization strategy) Способ вычислить новые параметры блока: максимизация {term}`Q-функции <Q-функция>`, {term}`правдоподобия наблюдаемых данных <Правдоподобие наблюдаемых данных>` или сопоставление моментов. В коде — перечисление `MaximizationStrategy`. См. [Стратегии M-шага](math/strategies/index.md).

Вес компоненты
  (weight) Вероятность $\omega_j$ того, что наблюдение порождено $j$-й компонентой. Веса неотрицательны и в сумме дают единицу; `MixtureModel` хранит их логарифмы.

E-шаг
  (expectation step) Шаг итерации, на котором по текущим параметрам вычисляются {term}`ответственности <Ответственность>` и тем самым {term}`Q-функция`. В коде — `ExpectationStep`.

Жёсткий E-шаг
  (hard E-step) Вариант {term}`E-шага <E-шаг>`, при котором каждое наблюдение целиком относится к компоненте с наибольшей {term}`ответственностью <Ответственность>`. Включается параметром `ExpectationStep(is_soft=False)`.

Компонента
  (component) Одно из распределений $f_j(\cdot \mid \theta_j)$, из которых складывается {term}`конечная смесь <Конечная смесь>`. В библиотеке — распределение `ParametricFamilyDistribution` из `pysatl-core`.

Критерий остановки
  (breakpointer) Правило, по которому конвейер решает, выполнять ли следующую итерацию, например по изменению правдоподобия или по числу итераций. В коде — подклассы `Breakpointer`.

Конечная смесь
  (finite mixture) Распределение с плотностью $\sum_j \omega_j f_j(x \mid \theta_j)$. В коде — `MixtureModel`. См. {ref}`math-mixture-density`.

M-шаг
  (maximization step) Шаг итерации, на котором параметры смеси обновляются так, чтобы увеличить {term}`Q-функцию <Q-функция>` или {term}`правдоподобие наблюдаемых данных <Правдоподобие наблюдаемых данных>`. В коде — `WeightsStep` для весов и `MaximizationStep` для параметров компонент.

Обобщённый EM
  (generalized EM, GEM) Итерация, которая не обязательно максимизирует {term}`Q-функцию <Q-функция>`, но не уменьшает её. Для неё уже верна монотонность правдоподобия. См. {prf:ref}`def-gem`.

Параметризация
  (parametrization) Способ задать параметры распределения одного семейства, например `meanStd` для нормального распределения. Аналитические стратегии M-шага выбираются по паре «семейство, параметризация».

Полные данные
  (complete data) Выборка вместе с ненаблюдаемыми метками компонент, породивших каждое наблюдение. См. {ref}`math-complete-data`.

Правдоподобие наблюдаемых данных
  (observed-data likelihood, ODL) Правдоподобие смеси по самой выборке, без меток компонент. Его логарифм считает `MixtureModel.loglikelihood`. См. {ref}`math-observed-loglik`.

Q-функция
  (Q-function) Математическое ожидание логарифма правдоподобия {term}`полных данных <Полные данные>` по распределению меток при текущих параметрах. См. {ref}`math-q-function`.

Удаление компонент
  (pruning) Удаление из смеси компонент по правилу, например с весом ниже порога, после {term}`M-шага <M-шаг>`. Веса оставшихся компонент перенормируются. В коде — подклассы `Pruner`.

Семейство
  (family) Параметрическое семейство распределений `pysatl-core`, например `Normal` или `Exponential`; в коде задаётся `FamilyName`.
```
